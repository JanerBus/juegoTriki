# 🎮 Juego de Triki (Tic-Tac-Toe)

Un proyecto web interactivo del clásico juego de Triki (también conocido como Tres en línea), desarrollado con HTML, CSS y JavaScript.

## 🚀 Características
*   **Interfaz Atractiva:** Diseño moderno con animaciones, sombras y colores vibrantes.
*   **Responsivo:** Se adapta perfectamente a pantallas pequeñas y grandes.
*   **Lógica de Juego:** Detección automática de ganador y de empates, impidiendo movimientos no válidos.
*   **Modularidad:** Código estructurado separando la maquetación (HTML), los estilos (CSS) y la interactividad (JS).

## 🕹️ ¿Cómo se juega?
El Triki es un juego para dos jugadores, **X** y **O**, que se turnan para marcar los espacios en una cuadrícula de 3×3.
El jugador que logre colocar tres de sus marcas en una fila horizontal, vertical o diagonal será el ganador.
